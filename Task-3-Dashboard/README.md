# Task 3 – E-Commerce Sales Dashboard

## 📊 Project Overview

This project is part of the **CodeOrbit Tech Data Analyst Internship – Batch IND1**.

The objective of Task 3 is to create an interactive and professional sales dashboard using spreadsheet tools. The dashboard summarizes e-commerce sales performance through key performance indicators (KPIs), charts, and business-focused visualizations.

The dashboard was created using **Neat Office Spreadsheet** and saved in Excel-compatible `.xlsx` format.

---

## 🎯 Objective

The main objectives of this task are to:

- Create a professional sales dashboard.
- Present important sales KPIs.
- Visualize revenue by category and region.
- Identify the top products by revenue.
- Present monthly revenue performance.
- Convert analyzed sales data into an easy-to-understand business report.

---

## 🛠️ Tools Used

- **Neat Office Spreadsheet**
- Excel-compatible `.xlsx` format
- Cleaned e-commerce sales dataset from Task 1
- Sales analysis results from Task 2

---

## 📁 Dataset

The dashboard uses the cleaned e-commerce sales dataset prepared during **Task 1 – Data Cleaning**.

The dataset contains information including:

- Order ID
- Customer Name
- Product
- Category
- Quantity
- Unit Price
- Order Date
- Region
- Revenue

The cleaned dataset contains **19 valid orders**.

## 💡 Business Insights

Based on the dashboard:

- The dataset records **₹395,700 in total revenue** across 19 orders.
- **Electronics** contributes the largest share of recorded revenue, with ₹358,100.
- The **South region** records the highest revenue among the regions in the dataset, with ₹258,700.
- The **Laptop** is the highest-revenue product in the dataset, generating ₹227,000.
- All recorded sales in the dataset occurred during **January 2026**.
- The average order value is approximately **₹20,826.32**.

These insights are descriptive of the provided dataset and should not be interpreted as trends beyond the available sample.

---

## 🔍 Dashboard Methodology

The dashboard was developed using the following process:

1. Imported the cleaned sales dataset.
2. Verified the available sales fields.
3. Calculated total revenue.
4. Calculated total orders.
5. Calculated total quantity sold.
6. Calculated average order value.
7. Summarized revenue by category.
8. Summarized revenue by region.
9. Calculated product-level revenue.
10. Identified the top 5 products by revenue.
11. Summarized revenue by month.
12. Created charts for each major analysis.
13. Arranged the KPIs and charts into a consolidated dashboard.
14. Checked the dashboard calculations against the total revenue.
