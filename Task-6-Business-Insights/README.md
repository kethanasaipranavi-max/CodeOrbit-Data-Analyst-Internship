# Task 6 – Mini Project: Business Insights Report

## Overview

This project was completed as the final mini project of the CodeOrbit Tech Data Analyst Internship – Batch IND1.

The objective was to analyze the cleaned e-commerce sales dataset and produce a business insights report based on the findings from the previous tasks.

## Objective

The main objectives of this project were to:

- Summarize overall sales performance
- Analyze category, regional, and product performance
- Identify important business insights
- Highlight data quality observations
- Provide practical action items based on the analysis
- Validate the reported metrics against the source dataset

## Tools Used

- Neat Office Spreadsheet
- Excel-compatible `.xlsx` format
- Cleaned e-commerce sales dataset
- Analysis results from Tasks 1–5

## Dataset Summary

The analysis was performed using the cleaned e-commerce sales dataset.

Key dataset metrics:

- Total Revenue: ₹395,700
- Total Orders: 19
- Total Quantity Sold: 43 units
- Average Order Value: ₹20,826.32

## Key Business Insights

### Category Performance

Electronics was the highest-revenue category, generating ₹358,100.

Furniture generated ₹34,000, while Uncategorized products generated ₹3,600.

### Regional Performance

South was the highest-revenue region with ₹258,700.

North generated ₹82,000, followed by West at ₹34,000 and East at ₹21,000.

### Product Performance

Laptop generated the highest product revenue at ₹227,000.

Monitor generated ₹75,000, followed by Office Chair at ₹34,000 and Headphones at ₹31,500.

### Data Quality Observation

Uncategorized products contributed ₹3,600 in revenue, indicating an opportunity to improve product category classification.

## Recommendations & Action Items

1. Monitor the Electronics category closely because it contributes the largest share of revenue.
2. Review sales performance in the South region to understand the factors contributing to its higher revenue.
3. Track Laptop sales and inventory because Laptop generated the highest product revenue.
4. Improve product category classification to reduce the amount of Uncategorized revenue.
5. Continue monitoring revenue, order volume, quantity sold, and average order value as core business KPIs.

## Validation

The final report was validated against the cleaned dataset and previous analysis tasks.

Validation checks confirmed:

- Total Revenue = ₹395,700 ✅
- Total Orders = 19 ✅
- Total Quantity Sold = 43 units ✅
- Average Order Value = ₹20,826.32 ✅
- Category, region, and product analysis reconcile with the dataset totals. ✅
